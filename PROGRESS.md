## Changes in this implementation phase

- Corrected release installation policy: physical Arch, compatible Arch-based systems, and VMs are supported subject to distro/dependency checks; VM detection no longer gates installation. Removed all `PYNIX_ALLOW_PHYSICAL` logic.
- Added fixture-based tests for physical/VM/inconclusive virtualization detection, containers, Arch-like OS identity, unsupported OS/architecture, mocked root checks, invalid paths, declined/Yes-to-All routine actions, repeatable deployment/removal functions, and preservation of unrelated files.
- Updated installation deployment/cleanup to include the project `assets/` directory; routine confirmation flows now support Yes, No, and Yes to All while the essential overall action remains separately confirmed.
- Added an application search window and a Python standard-library desktop-entry helper that delegates launching to the GTK desktop-entry launcher without shell command construction.
- Replaced the in-memory-only notification stub with Quickshell's documented notification server, active notification tracking/dismissal, and a Control Center notification tile. Added persisted visible-count controls to Settings.
- Added isolated desktop-entry parsing/launch tests and source-contract assertions for launcher/notification service wiring.
- Added a Quickshell `IpcHandler` with safe commands against shared root state, plus an IPC bridge that selects `qs`/`quickshell` and rejects unsupported command names.
- Added opt-in `--keybindings` integration for Lua and legacy hyprlang config formats. Bindings live in the existing backed-up, marker-delimited block and are removed with it; default installation adds no keybindings.
- Added focused tests for all IPC bridge command routing/fallback/error cases and reversible, idempotent optional Lua/hyprlang keybinding blocks.
- Added a shared UPower battery service, compact theme-colored status circles, and persistent indicator visibility/order controls. Runtime-dependent states remain sourced from NetworkManager, BlueZ, PipeWire, and UPower instead of saved settings.
- Added persisted two-column Control Center tile coordinates, span-aware overlap/boundary validation, legacy/malformed-layout normalization, direct positioning, drag swapping, context-menu resizing, directional keyboard controls, and complete layout/preset undo snapshots. The live Control Center now renders the same grid; the GUI remains unverified.

- Replaced the fixed-size Qt Quick `Window` with a Quickshell `ShellRoot`, per-screen `PanelWindow`, click-through input mask, clickable compact/expanded island, live clock, MPRIS metadata and capability-aware playback controls.
- Connected `MediaService.qml` to Quickshell's MPRIS player model and limited position refresh to one-second updates while playing.
- Connected audio state and controls to PipeWire's default sink, binding it through `PwObjectTracker` before reading or changing writable audio properties.
- Replaced synchronous XMLHttpRequest settings handling with Quickshell `FileView`/`JsonAdapter` persistence in the installed PyNix Shell user config directory.
- Added functional Control Center controls for audio mute/volume, theme selection, reduced motion, and low-performance mode.
- Added static source-contract assertions for the QML runtime and service APIs to `tests/test_config.py`; these assertions have now passed.
- Added `src/SettingsWindow.qml`, `src/SettingsRow.qml`, `src/LayoutEditor.qml`, and `src/ControlCenter.qml`; the nine Settings pages have specific behavior/status content, and supported tile selection, order, sizing, and preview dimensions are shared between live panel and editor.
- Expanded and normalized the persistent preference schema; layout operations validate tile IDs/sizes, preserve an undo history, and recover malformed saved layouts.
- Wired clock/date, island geometry, artwork size, hover lift, animation mode/durations, Control Center geometry, and tile enabled state/order/size to the running UI.
- Replaced NetworkManager, BlueZ, and brightness placeholders with shared Quickshell networking/Bluetooth services and optional debounced `brightnessctl` reads/writes; connected their actual state, operations, errors, and fallback status to the Control Center and System page.
- Added Wi-Fi network selection and transient password entry for supported PSK networks. PyNix does not log or persist credentials; NetworkManager may manage a supplied credential in its system profile.
- Added Wi-Fi, Bluetooth, and brightness to supported Control Center layouts, defaults, presets, editor summaries, and shared layout sizing.
- Updated product requirements, README, decisions, and progress to separate the release goals from the actual incomplete installer and UI.
- Added ASCII installer branding and missing-required-package handling for Python, Quickshell, and Hyprland. Package availability, declined operations, Y/N/Yes-to-All consent, the sudo command boundary, and post-install package verification are covered with mocked tests; real sudo/pacman execution remains intentionally untested.

## Public API documentation consulted

- Quickshell 0.3.2 [`QsWindow.mask`](https://quickshell.org/docs/v0.3.2/types/Quickshell/QsWindow#mask) and [`Region`](https://quickshell.org/docs/v0.3.2/types/Quickshell/Region) document click-through window regions.
- Quickshell 0.3.2 [`Mpris`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Mpris/Mpris) and [`MprisPlayer`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Mpris/MprisPlayer) document the player model, metadata, playback capabilities, and position-update guidance.
- Quickshell 0.3.2 [`Pipewire`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Pipewire/Pipewire), [`PwObjectTracker`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Pipewire/PwObjectTracker), and [`PwNodeAudio`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Pipewire/PwNodeAudio) document default output access and node binding requirements.
- Quickshell 0.3.2 [`FileView`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/FileView) and [`JsonAdapter`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/JsonAdapter) document JSON persistence; the runtime chooses the install-owned XDG config path so the existing uninstaller can offer to preserve or remove that file.
- Qt 6 [`Drag`](https://doc.qt.io/qt-6/qml-qtquick-drag.html), [`DropArea`](https://doc.qt.io/qt-6/qml-qtquick-droparea.html), [`DragEvent`](https://doc.qt.io/qt-6/qml-qtquick-dragevent.html), and [`SpinBox`](https://doc.qt.io/qt-6/qml-qtquick-controls-spinbox.html) docs support the QML drag/drop and editor control APIs used in source.
- Quickshell 0.3.2 [`Networking`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/Networking), [`NetworkDevice`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/NetworkDevice), [`WifiDevice`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/WifiDevice), [`WifiNetwork`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/WifiNetwork), [`ConnectionState`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/ConnectionState), and [`ConnectionFailReason`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/ConnectionFailReason) document the NetworkManager-backed state and connection APIs.
- Quickshell 0.3.2 [`Bluetooth`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Bluetooth/Bluetooth), [`BluetoothAdapter`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Bluetooth/BluetoothAdapter), and [`BluetoothDevice`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Bluetooth/BluetoothDevice) document BlueZ-backed adapter and connected-device properties.
- Quickshell 0.3.2 [`Process`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/Process) and [`StdioCollector`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/StdioCollector), plus the upstream [`brightnessctl` usage`](https://github.com/Hummer12007/brightnessctl), document the argument-list process and machine-readable backlight mechanism.
- Quickshell 0.3.2 [`NotificationServer`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Notifications/NotificationServer), [`Notification`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Notifications/Notification), and [`FloatingWindow`](https://quickshell.org/docs/v0.3.2/types/Quickshell/FloatingWindow) document active notification tracking/dismissal and the launcher window type; the Freedesktop [`desktop-entry specification`](https://specifications.freedesktop.org/desktop-entry/latest/exec-variables.html) and GTK [`gtk4-launch`](https://docs.gtk.org/gtk4/gtk4-launch.html) documentation support safe desktop-ID delegation.
- Quickshell 0.3.2 [`IpcHandler`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/IpcHandler) documents typed IPC functions and `qs ipc call`; official Hyprland [`Lua configuration`](https://wiki.hypr.land/0.55.0/Configuring/Start/), [`Lua bind example`](https://github.com/hyprwm/Hyprland/blob/main/example/hyprland.lua), and [legacy hyprlang binds](https://wiki.hypr.land/0.54.0/Configuring/Binds/) were checked for the optional shortcut syntax.
- Quickshell 0.3.2 [`UPower`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.UPower/UPower), [`UPowerDevice`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.UPower/UPowerDevice), and [`UPowerDeviceState`](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.UPower/UPowerDeviceState) document battery discovery, presence, readiness, percentage, and charge-state APIs.
